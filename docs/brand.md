# Imagen de marca

`custom_components/miantel/brand/icon.png` es una copia sin modificar del recurso `res/mipmap-xxxhdpi/ic_miantel_icon.png` de MiAntel Android 2.12.1. Se usa para identificar visualmente el servicio en Home Assistant.

La imagen y las marcas MiAntel y Antel pertenecen a sus respectivos titulares; no están incluidas en la licencia MIT del código de esta integración comunitaria. La integración no está afiliada a Antel.

Home Assistant admite la carpeta local `brand/` en integraciones personalizadas desde 2026.3: [documentación oficial](https://developers.home-assistant.io/docs/core/integration/brand_images/).
